# RiMwa

Baca komik online. Express + API + frontend vanilla ES modules.
Dark UI, flat, padat, Poppins.

## Jalankan
```bash
npm install
npm start
```

Env opsional: `PORT`, `IMG_HOSTS` (lihat `.env.example`).

## Struktur
```
├── src/          # server, routes, services, middleware
└── public/       # html, css, js
```
